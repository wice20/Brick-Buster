# Brick Buster

A classic brick breaker game built with HTML, CSS, and JavaScript.

## How to Play
- Click Start Game to begin
- Use left and right arrow keys to move the paddle
- Break all the bricks to advance to the next level
- You have 3 lives, the game ends
- When the ball hits the bottom of the screen you lose a life, and when you lose all 3 lives
- If there is an interruption while playing the game, you can reset the game using the reset button

## Features
- Start screen
- Multiple levels that get harder
- Score tracking
- Lives system
- Background music and sound effects
- Restart button

## Built With
- HTML
- CSS
- JavaScript
